# ฐานเดิมสำหรับการย้ายโครงสร้าง

- หน้ารับชำระเดิมอยู่ที่ `lib/Account/Account_Invoce_pay.dart` และใช้ `lib/Model/GetTrans_Model.dart` สำหรับข้อมูลรายการ
- งานปรับหน้ารับชำระและโครงสร้าง MVVM ติดตามใน GitHub issue #158 และ #164 โฟลเดอร์เป้าหมายคือ `lib/Account/Account_Invoce_pay/`; การมีเอกสารนี้ไม่ได้หมายความว่าการย้ายเสร็จแล้ว
- ตรวจ navigation, สิทธิ์, API, state และขั้นตอนรับชำระเดิมก่อนย้ายแต่ละส่วน รักษา contract และพฤติกรรมเดิม เว้นแต่มีการตกลงเปลี่ยนแปลง
- ก่อนแก้ไฟล์ ตรวจงานที่ยังไม่ได้ commit และรักษาการแก้ไขที่ไม่เกี่ยวข้อง ไม่ใช้ข้อมูลตัวอย่างแทนข้อมูล API จริง
- กรณีข้อมูลการเงินหรือพฤติกรรม API ยังไม่ชัดเจน ให้บันทึกข้อจำกัดและยืนยันก่อนเปลี่ยนสูตรหรือขั้นตอนบันทึก
