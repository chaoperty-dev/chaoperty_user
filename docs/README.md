# เอกสารโครงการ

โครงสร้างนี้อ้างอิงแนวทางจากโปรเจกต์ `chiangMai-municipality` โดยปรับเนื้อหาให้ตรงกับ repository นี้

- `specs/` — ขอบเขต พฤติกรรม API และเกณฑ์ตรวจรับของแต่ละ feature
- `adr/` — เหตุผล ทางเลือก และผลกระทบของการตัดสินใจด้านสถาปัตยกรรม
- `architecture/` — ภาพรวมระบบเดิมและข้อควรระวังในการย้ายโครงสร้าง
- `superpowers/plans/` — แผนดำเนินงานที่ได้รับการกำหนดสำหรับแต่ละเรื่อง

เอกสารเป็นข้อมูลประกอบการพัฒนา ไม่ใช่หลักฐานว่าฟังก์ชัน implement หรือทดสอบผ่านแล้ว อัปเดตสถานะตามผลจริงและไม่ใส่ credentials หรือข้อมูลส่วนบุคคล
